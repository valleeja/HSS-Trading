# The map of the app: the box every source file of the workspace belongs to (split into modules, AIP-0001).
#
# One line: a path under rust/, then its box. A path that ends with `/` is a folder: it holds for every file under
# it that has no closer line (the longest path wins).
#
# The boxes:
#   A Carnet · B Flux d'ordres · C Marchés · E Watchlist · F Alertes · G Actualités et calendrier
#   J Chart · H Argos Script · I Argos AI · D Scanner
#   L Trading démo · M Portefeuille et journal · N Simulateur · K Bots et stratégies · O PropFirm · P Académie
#   Q Compte · R Communauté · S Support · T Marketplace · U Gagner · V Langues · W Interface
#   KIT the drawing kit · DON the shared data · BASE the base types
#   COQ the shell (window, switchboards, modules, vault) · MIX a mixed file, to be cut up between its modules
#   TESTS the tests of the whole app (they may name everything: their links are not counted)
#
# Written by hand, never by a test. A new source file gets its line here, in the box of the module it is part of:
# `every_source_file_is_on_the_map` fails until it has one.
