# Range, accumulation et distribution (Wyckoff)

> Parcours 2 · Structure SMC · 6 min · Le cadre qui explique le « pourquoi » des ranges.

## ⚡ En 30 secondes
Le marché tourne en 4 phases : accumulation (range après une baisse), markup (hausse), distribution (range après une hausse), markdown (baisse). Dans le range, les gros joueurs se placent discrètement. Le spring est le sweep qui précède la vraie sortie.

## 📋 Le cycle
| Phase | Nom | Ce qui se passe |
|---|---|---|
| 1 | Accumulation | Range après une baisse ; achats discrets |
| 2 | Markup | Sortie du range, hausse évidente |
| 3 | Distribution | Range après une hausse ; ventes aux acheteurs tardifs |
| 4 | Markdown | Sortie du range, baisse évidente |

## 🎓 Niveau avancé : le schéma A–E
<details><summary>Le cycle en 4 temps ci-dessus est le cycle macro. Le schéma détaillé de Wyckoff découpe chaque range en 5 phases avec des événements nommés.</summary>

**Accumulation**
| Phase | Événements | Ce que ça veut dire |
|---|---|---|
| A | PS (support préliminaire), SC (selling climax), AR (rebond automatique), ST (test secondaire) | La baisse s'arrête : panique, puis premier rebond |
| B | Allers-retours dans le range | Les gros absorbent l'offre, longtemps |
| C | Spring (faux plancher) + Test, ou LPS | Le dernier piège : sweep sous le range, puis retour dedans |
| D | SOS (signe de force), JAC (saut du ruisseau), BU (retour) | Sortie du range par le haut, retest |
| E | Markup | La tendance haussière est lancée |

**Distribution** : mêmes phases en miroir : PSY, BC (buying climax), AR, ST (A) ; range (B) ; UT / UTAD (upthrust, le sweep au-dessus) (C) ; SOW (signe de faiblesse), LPSY (D) ; Markdown (E).

En SMC : le Spring est un liquidity sweep, le SOS est un BOS, le LPS est le retest d'un order block. Même film, autres mots.
</details>

## 🔍 Éléments clés d'une accumulation
- **Spring :** fausse cassure sous le range (un sweep) qui piège les vendeurs.
- **Sign of Strength (SOS) :** première impulsion forte des acheteurs.
- **Test :** retour sur la zone du spring pour vérifier que ça tient.
La distribution a l'inverse : **upthrust** à la place du spring.

## 🧠 Pourquoi c'est le liant
Les BOS, CHoCH, order blocks, FVG et sweeps s'imbriquent dans ce cadre : le range n'est pas « rien », c'est une phase active.

## 🎯 En pratique
1. Range prolongé après une tendance forte → suspecte une accumulation ou une distribution.
2. Cherche le spring (ou l'upthrust) comme entrée précoce.
3. Confirme avec un CHoCH/BOS et le SOS.
4. Cible : la sortie du range, mesurée par sa hauteur.

## 🪤 Pièges
- Voir des phases Wyckoff partout après coup.
- Confondre un range qui ne donnera rien avec une accumulation.

## ⚠️ Limite honnête
Très difficile en direct ; les phases durent des semaines ou des mois. Patience et discipline.

## ✅ Check-list
- [ ] Range après une tendance forte
- [ ] Spring ou upthrust repéré
- [ ] SOS et test observés
- [ ] CHoCH/BOS de confirmation

## ❓ Quiz
1. Les 4 phases : → **accumulation, markup, distribution, markdown** ~ sweep, MSS, FVG, cible ~ ouverture, manipulation, expansion, clôture
2. Le spring est : → **une fausse cassure sous le range** ~ une vraie cassure vers le haut ~ la première phase du range
3. L'équivalent du spring en distribution : → **l'upthrust** ~ le selling climax ~ le SOS
4. Le SOS est : → **la première impulsion forte des acheteurs** ~ la dernière chute avant le range ~ un sweep sous le range
5. Un range après une forte tendance est souvent : → **une phase active d'accumulation ou de distribution** ~ sans intérêt ~ toujours une continuation
