# Writing indicators for Argos HSS Trading (2026-11-22)

| File | What it is |
|---|---|
| `argos-script-reference.md` | The Argos Script reference, in French, for users: the language, drawing, settings, recipes. |
| `argos-script-llms.txt` | The same reference in English, written for AI assistants. |
| `creer-indicateur-rust.md` | « Créer un indicateur en Rust », in French: a WASM module with the kit Argos, step by step. |
| `creer-indicateur-rust-llms.txt` | The same in English for AI assistants, with the module example that compiled. |

To write an indicator with an AI assistant, give it the doc and its llms file. The recipes of the reference are
test fixtures in `pine/argos/recettes/` (run by `argos-script`'s `recettes_de_la_reference`).
